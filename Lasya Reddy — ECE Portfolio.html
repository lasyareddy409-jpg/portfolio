PROJECT · CBPL

HIGH-SPEED LiFi DATA TRANSFER
USING LASER COMMUNICATION

Designed and built an optical wireless link that transmits data over a modulated laser beam and recovers it at a photodetector receiver. The system demonstrates high-speed, line-of-sight transfer without using the radio spectrum — a practical look at LiFi as an alternative to conventional wireless.

  • Laser transmitter with modulated data signal
  • Photodetector receiver and demodulation circuit
  • High-speed line-of-sight optical link
  • Submitted as a Capstone Based Project Learning (CBPL) project

PROJECT · IoT

OBSTACLE AVOIDING ROBOT

An autonomous rover that senses its surroundings in real time and reroutes itself before impact. Ultrasonic distance data is processed by a microcontroller which drives the motors — navigation with no map and no driver.

  • Real-time ultrasonic distance sensing and threshold logic
  • Motor driver control for autonomous steering
  • Arduino-based embedded firmware
  • Built and tested as a college IoT project
